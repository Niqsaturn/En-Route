# Production installer required

No installer or portable EXE is committed to this GitHub branch.

The HTML currently links to `downloads/EnRoutePatcher.exe` solely for the *local offline review copy*, which includes an owner's installed portable GUI patcher.

Before any website deployment, replace the link in both `index.html` CTAs with a verified release URL for an audited first-time installer, not a raw portable updater.

Do not upload production secrets, player data, private signed-feed keys, or credential files.
